# ACG Executive V3 pilote
Copier demandes.php dans congo-suite/api/executive/ existant. Copier executive_mobile.php de chaque dossier serveur à la racine de son application respective. EasyStock : copier executive_db.example.php en executive_db.php et renseigner les paramètres de sa base ACG. Sur chaque serveur créer executive_secret.php contenant <?php return 'CLE_SECRETE_IDENTIQUE'; (au moins 32 caractères, clé Executive existante renouvelée si nécessaire). Ne jamais envoyer ces fichiers secrets sur GitHub. Utiliser HTTPS uniquement.
Dans l’APK renseigner les trois URL racines et la même clé. Authentification par clé partagée, pas encore compte BOSS individuel. Lecture seule. Aucun SQL de migration. Les montants restent séparés par devise, commandes distinctes des factures. RH, notifications, PDF, marges, pagination complète et authentification individuelle non inclus. Vérifier les résultats contre les applications web.
GitHub : conserver appId, envoyer src, public, index.html, package.json, capacitor.config.json et .github du projet. Ne pas envoyer SERVEUR_PHP. Workflow existant produit APK debug.
